# Página de Receita
Projeto desenvolvido durante as aulas da **Rocketseat**, com o objetivo de praticar os fundamentos do desenvolvimento front-end e compreender melhor a construção de páginas web.

## Sobre o projeto:
A proposta foi desenvolver uma página de receita, aplicando os conceitos apresentados pelo professor e acompanhando as etapas de construção do layout.Durante a atividade, utilizamos o **Figma** como referência visual para compreender a organização dos elementos, identificar espaçamentos, caixas, tipografia e cores, transformando o design em uma página web.

## O que pratiquei:

- Fundamentos de HTML e CSS.
- Estruturação e organização dos elementos HTML.
- Construção de layouts e identificação de caixas e espaçamentos.
- Aplicação de fontes, cores e estilos.
- Interpretação de referências visuais utilizando o Figma.
- Consulta à documentação técnica por meio do DevDocs.
- Reprodução de um layout a partir de uma referência de design.

## Tecnologias e ferramentas:

- HTML5
- CSS3
- Figma
- DevDocs
- Visual Studio Code

## Objetivo de aprendizagem:

Consolidar os primeiros conhecimentos de desenvolvimento front-end, entendendo como transformar uma referência visual em uma página web estruturada e estilizada, além de desenvolver o hábito de consultar documentações técnicas durante o processo de desenvolvimento.
